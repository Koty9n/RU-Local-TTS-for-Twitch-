# <a href="https://github.com/Koty9n/">Koty9n</a><a href="https://github.com/Koty9n/RU-Local-TTS-for-Twitch">/RU-Local-TTS-for-Twitch</a>

**RU Local TTS for Twitch — озвучка чата Twitch для стримеров: русская GLaDOS, голоса Piper, ударения и панель-док для OBS**  
Работает на процессоре, видеокарта не нужна. Всё хранится в одной папке — удалил папку, и программы нет.

## Возможности

-  Русская **GLaDOS** (движок TeraTTS) и голоса **Piper** (IGM, Mari, Women, Сказочник), можно добавить свой `.onnx`
-  Автоматические ударения (RUAccent) + свой словарь ударений
-  Озвучка **наградой за баллы канала** для зрителей и командой `!!!текст` для модеров, владельца и VIP
-  Панель-док для **OBS**: пропуск, громкость, голос, доступ, чёрный список, словарь, журнал
-  Чёрный список слов, баны и муты, защита от спама и повторов
-  Лёгкая: ~20% CPU и около 1 ГБ памяти под нагрузкой, уступает процессор игре и OBS

## Использование

1. Нажмите **Code → Download ZIP** на этой странице (или скачайте архив из [релизов](https://github.com/Koty9n/RU-Local-TTS-for-Twitch/releases/latest), если он там есть)

2. Зайдите в свойства скачанного архива и поставьте галочку «Разблокировать». Если вы используете 7-Zip или PeaZip, этот шаг можно пропустить

3. Распакуйте архив в папку, **путь к которой не содержит кириллицу/спец. символы** (запускать прямо из архива нельзя)

4. Запустите **`start_tts.bat`**: откроется установщик (6 шагов, ничего трогать не нужно, нужно около 1,5 ГБ места и 5–10 минут)
    * На шаге 4 появится окно «Голоса для TTS»: отметьте нужные и нажмите «Скачать». GLaDOS ~210 МБ, остальные ~61 МБ каждый
    * Не скачанные голоса можно докачать позже: «Голоса» → «Скачать голоса…»

5. Войдите в Twitch: «Войти через Twitch» → в браузере нажмите «Activate» / «Разрешить». Входить нужно в аккаунт того канала, чей чат будет озвучиваться

6. На вкладке «Главная» нажмите **«Подключиться»**, должно загореться зелёным «Подключён к чату»

7. Звук в OBS: источник **«Захват звука приложения»** → `pythonw.exe` (или своё устройство вывода в «Настройках»)

Пошаговая инструкция для новичка: [**`КАК УСТАНОВИТЬ.txt`**](./КАК%20УСТАНОВИТЬ.txt)

## Краткие описания файлов

- [**`start_tts.bat`**](./start_tts.bat) - запуск программы; при первом запуске открывает установщик [`install.ps1`](./install.ps1)
- [**`ОБНОВИТЬ.bat`**](./ОБНОВИТЬ.bat) - обновление программы без потери настроек:
  - берёт свежий архив `TwitchTTS*.zip` из «Загрузок»/рабочего стола
  - меняет только код (старый сохраняется в `_backup\обновление_<дата>`)
  - не трогает `config.json`, `data\`, голоса и `venv`
  - в старой версии файла нет: запустите `ОБНОВИТЬ.bat` из распакованного нового архива и укажите папку программы
- [**`test_glados.bat`**](./test_glados.bat) - проверка звучания GLaDOS
- [**`config.example.json`**](./config.example.json) - пример настроек (рабочий `config.json` создаётся программой)
- [**`data\`**](./data) - готовые списки: `replacements_twitch.txt` (словарь замен), `blacklist_twitch.txt` (чёрный список), `stress_dict.txt` (ударения для GLaDOS)
- [**`ЧТО НОВОГО.txt`**](./ЧТО%20НОВОГО.txt) - список изменений

## Команды и доступ

**Кто озвучивает**
- Зрители - наградой за баллы канала. Награду создаёт сам бот: панель → «Доступ» → «Создать награду» или `!!!tts reward create 500`
- Модеры, владелец, VIP и список разрешённых - сообщением `!!!текст`

| Команда | Кто | Что делает |
|---|---|---|
| `!tts` / `!tts <голос>` | все | список голосов / выбрать свой |
| `!skip` | модеры | пропустить текущую озвучку |
| `!!!tts add\|del <ник…>`, `set <ник…>`, `list` | модеры | кому можно `!!!` |
| `!!!tts ban\|unban <слово>` | модеры | чёрный список |
| `!!!tts reward create [цена]`, `price <N>` | владелец | награда и её цена |
| `!!!tts reload` | модеры | перечитать голоса, списки, словарь |
| `!!!tts block <ник>`, `unblock <ник>` | модеры | запретить TTS насовсем, даже VIP и модерам |
| `!tts mute <ник> [мин]`, `!tts unmute <ник>` | модеры | запретить TTS на время (по умолчанию 10 мин) |

В тексте награды: `!tts mari привет` - сменить голос и озвучить, `!tts mari` - только сменить.  
Удалённые модером сообщения, бан и очистка чата обрывают озвучку. Запрещённым и замученным бот не озвучивает ни `!!!`, ни баллы
(баллы спишутся: вернуть вручную в очереди наград).

## Панель в OBS

1. В программе: «Главная» → «Копировать»
2. В OBS: «Док-панели» → «Пользовательские док-панели браузера…» → имя `TTS`, адрес - скопированная ссылка → «Применить»

Вкладки: **Пульт** (пропуск, громкость, голос, проверка), **Доступ**, **Словарь**, **Журнал**.

> [!CAUTION]
> В адресе панели секретный ключ. **Не показывайте его на стриме.**

## Настройка

**Голоса**
- Свой голос Piper: «Добавить свой…» (`.onnx` + `.onnx.json`)
- Ударения ставятся сами; свои: `з+амок` в тексте или `data\stress_dict.txt` (`слово=сл+ово`, для GLaDOS)
- Звучание «р» у GLaDOS: `test_glados.bat`, затем `"tera_r_fix": "double"` в `config.json`, если так лучше

**Тексты**
- **Словарь замен** (`minecraft = майнкрафт`, `gg = гэгэ`): готовый `data\replacements_twitch.txt`, свой - `data\replacements.txt` или панель → «Словарь»
- **Чёрный список**: `data\blacklist.txt` (свой), `data\blacklist_twitch.txt` (готовый). Слова от 4 букв ловятся и внутри слова, и буквами врозь («с у к а»), короткие - только целиком

<details>
<summary><b>Полезные ключи <code>config.json</code></b></summary>

| Ключ | Что делает |
|---|---|
| `max_chars`, `user_cooldown_sec`, `max_queue` | длина сообщения, пауза между сообщениями одного зрителя, размер очереди |
| `say_name` | читать ник автора |
| `volume`, `audio_device` | громкость и устройство вывода |
| `replace_on`, `replace_strip_emoji` | словарь замен и удаление неизвестных эмодзи |
| `accent_on`, `accent_model`, `accent_light` | ударения; `accent_light` - ~1 ГБ памяти вместо ~4 ГБ |
| `tera_unload_min` | выгружать GLaDOS после N минут простоя (0 - держать) |
| `tera_preload`, `glados_autoinstall` | предзагрузка и автоустановка GLaDOS |
| `cpu_threads` | ядер на нейросеть: 3 по умолчанию (~20% CPU), 2 - ещё легче, 0 - все ядра |
| `low_priority` | `true` - игра и OBS получают процессор первыми |
| `dup_window_sec` | одинаковое сообщение за N секунд читается один раз (30; 0 - выключить) |
| `voice_cache` | сколько голосов Piper держать в памяти (4) |

После правки перезапустите программу.

## Распространенные вопросы и проблемы

### Установка оборвалась
- Запустите `start_tts.bat` ещё раз: уже скачанное пропускается
- Журнал установки: `data\install.log`. Если ничего не помогло, приложите его к обращению во вкладке [Issues](https://github.com/Koty9n/RU-Local-TTS-for-Twitch/issues)

### Нет звука
- «Настройки» → «Устройство вывода звука», проверьте громкость в панели
- В OBS: «Захват звука приложения» → `pythonw.exe` (программа должна быть запущена)

### «Twitch отклонил токен»
- «Настройки» → «Войти через Twitch…» и войдите ещё раз. Запасной способ: кнопка «Старый способ (twitchtokengenerator)» или свой токен вручную

### Нет голоса GLaDOS
- «Голоса» → «Скачать голоса…»

### GLaDOS работает медленно
- Тайминги каждой фразы - в `data\tera_worker.log`
- Слабый компьютер: `"cpu_threads": 2` в `config.json`

### Программа ест около 3 ГБ памяти
- У вас версия до 22.10: обновите через `ОБНОВИТЬ.bat`. В новой версии вся программа под нагрузкой занимает около 1 ГБ

### Как удалить
- Удалите папку программы и ярлык с рабочего стола. В систему ничего не устанавливается
